규정을 삭제하시겠습니까?

삭제된 규정은 왕십리역 전체 직원 화면에서 즉시 제거되며 복구할 수 없습니다.

홈 화면 '내규' 아이콘 설치 안내

내규

코레일 블루 '내규' 전용 아이콘 적용 완료

GitHub Pages 주소로 접속해 브라우저에서 홈 화면에 추가하면 바탕화면에 파란색 '내규' 아이콘이 자동 생성됩니다.

  1. 1 삼성 인터넷 또는 Chrome 우측 상단(또는 하단)의 메뉴(≡ 또는 ⋮)를 누릅니다.
  2. 2 '현재 페이지 추가' → '홈 화면'(또는 '홈 화면에 추가')을 선택합니다.
  3. 3 이름을 '내규'로 확인한 뒤 추가하면 바탕화면에 내규 아이콘이 생성됩니다.
  1. 1 iPhone의 Safari 브라우저 하단 중앙 공유 버튼(□↑)을 탭합니다.
  2. 2 메뉴를 아래로 내려 '홈 화면에 추가'를 선택합니다.
  3. 3 이름이 '내규'로 표시되는지 확인하고 우측 상단 '추가'를 누릅니다.
